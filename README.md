# stamptoml

Stamp CSV/TSV toml tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/stamptoml/

## Install / run

```bash
git clone https://github.com/theworker02/stamptoml.git
cd stamptoml
node src/cli.js
node --test
```
